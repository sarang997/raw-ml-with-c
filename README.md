
# raw-ml-with-c

Building ML fundamentals from scratch in C — no frameworks, no autograd,
just pointers and flat arrays. I am not using any copilot for coding assistance. 

## Approach
This project is intentionally built without using coding assistants or code-generation tools. The goal is to write the implementations from scratch and develop a deeper understanding of low-level concepts such as memory management, data structures, and the operations behind modern ML systems.
I am not against using coding assistants, they are valuable tools for productivity and development. However, for this project, I have chosen not to use them for writing code because the focus is on the learning process.
I use Claude as a learning tool to help understand concepts, discuss ideas, and reason through problems, but the implementation and code are written manually.

## Why
Most ML work happens at the PyTorch/numpy layer. This is the layer underneath —
understanding what a tensor actually *is* in memory, and how the operations
on it actually get computed.
